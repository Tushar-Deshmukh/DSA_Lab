**Matrices.** A matrix is an array of row arrays: `grid[r][c]`, rows `0..m-1`, columns `0..n-1`. Common moves are 4-directional (`[[1,0],[-1,0],[0,1],[0,-1]]`). Always bounds-check before indexing; `grid[-1]` is `undefined`, so `grid[-1][0]` throws.
