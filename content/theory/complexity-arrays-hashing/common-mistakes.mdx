**Common mistakes in this module.** Forgetting that `includes`/`indexOf` inside a loop is O(n²); using `for...in` on arrays (iterates string keys, including inherited ones); calling `Object.keys(obj).length` repeatedly (O(k) each time); mutating an array while iterating it with `forEach`; forgetting empty-array and single-element cases.
