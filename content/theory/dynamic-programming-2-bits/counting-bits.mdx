**Counting bits.** Brian Kernighan's loop removes one set bit per iteration (`while (x) { x &= x - 1; count++ }`), so it runs once per set bit. For all numbers 0..n (338), DP: `bits[i] = bits[i >> 1] + (i & 1)`.
