**Bitmasks.** An integer with n bits can represent a subset of n ≤ 30 items: bit i set ⇔ item i included. Iterate subsets with `for (let mask = 0; mask < (1 << n); mask++)`. Useful for n ≤ 20; deeper bitmask DP is deferred.
