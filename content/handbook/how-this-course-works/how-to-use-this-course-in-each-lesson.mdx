1. Open the lesson. It lists the topic, implementation exercise, problems, revision warm-up and completion criteria.
2. Read the lesson's theory during its 20–30 minute theory block.
3. Look up each problem's hint and purpose in the **problem bank** only after 10 minutes of independent thinking.
4. Use the method in **section 7** on every problem. Paste reusable code from **section 6** only after you can write it yourself.
5. Log every attempt in the tracker from **section 8**. At each module's checkpoint, fill the module scorecard in **section 10**.
