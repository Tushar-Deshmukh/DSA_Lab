Every lesson is about 2 hours; each module ends with a review, assessment or mock at its checkpoint. Problems are listed by LeetCode number; open the problem bank for links, hints and purpose.

**How to read each lesson.**

- **Problems:** **C** = Core (required), **S** = Stretch (same lesson if time, else later), **O** = Optional (Hard/advanced; skip freely).
- **Time:** minutes for **T**heory · **I**mplementation/dry run · **P**ractice (includes the 10-minute warm-up) · **R**eview of solutions and complexity · **N**otes. The default lesson is T25 · I15 · P60 · R15 · N5.
- **Warm-up:** the first 10 minutes of Practice. Re-solve the named problem from a blank editor (spaced repetition: +1, +3, +7, +14 days). If it is not done within those 10 minutes, stop, log it as "not retained" and schedule it again in 2 days.
- **Done when:** the completion criteria. Reading theory does not complete a lesson.

Per-problem time boxes in lessons: Easy 15 minutes, Medium 25 minutes, Hard 40 minutes before using the hint ladder in section 8 (assessments, mocks and Module 12 use the longer limits given there). Two Core Mediums at 25 minutes each fill the 50-minute Practice block, which is why the plan puts at most two unfamiliar Mediums in one lesson. If a Core problem is still unfinished when the block ends, it becomes the first item of that module's checkpoint review, replacing one re-solve; log it as "spilled".
