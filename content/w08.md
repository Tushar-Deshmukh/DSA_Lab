```ex
solution: |
  function numIslandsBFS(grid) {
    const m = grid.length, n = grid[0].length;
    const seen = Array.from({ length: m }, () => new Array(n).fill(false));
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    let count = 0;
    for (let r = 0; r < m; r++) for (let c = 0; c < n; c++) {
      if (grid[r][c] !== '1' || seen[r][c]) continue;
      count++; seen[r][c] = true;
      const q = [[r, c]];
      for (let h = 0; h < q.length; h++) {
        const [cr, cc] = q[h];

          seen[nr][nc] = true; q.push([nr, nc]);
        }
      }
    }
    return count;
  }
```

## Cloning a graph (Stretch) {theory}

Clone Graph (133) gives you one node of a connected undirected graph and asks for a deep copy. A `Map` from each original node to its copy does two jobs: it is the visited set (a node is visited iff it has a copy), and it is how you wire a copy's neighbours to the *copies* of the original's neighbours. Create a node's copy the first time you see it; then traverse and push each copy's neighbour list.

```ex

    why: "It can have cycles (1–2–3–1); the map is what prevents infinite loops."
```

```ex
solution: |
  function shortestPath(n, edges, src, dst) {
    const adj = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) { adj[u].push(v); adj[v].push(u); }
    const dist = new Array(n).fill(-1);
    dist[src] = 0;

      if (u === dst) return dist[u];

    }
    return -1;
  }
```

## 8 directions and blocked ends {theory}

Shortest Path in Binary Matrix (1091) adds two details: moves go in 8 directions, and the path length counts **cells** (so the start alone is length 1). If the start or the end cell is blocked, the answer is −1 before any search.

@viz grid-bfs

:::tip Optional: Word Ladder (127)
An implicit graph: words are nodes and two words are adjacent if they differ by one letter. Comparing every pair of words is O(N² · L). Instead bucket words by patterns with one wildcard (`h*t` → hot, hit); words in the same bucket are neighbours. Then it is plain BFS.
:::
