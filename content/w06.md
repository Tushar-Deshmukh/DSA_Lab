```ex
  function preorderIter(root) {

      const node = stack.pop();
```

## Minimum depth: stop at the first leaf (Stretch) {theory}

Minimum Depth (111) is where BFS beats DFS: levels are visited in order, so the first leaf BFS dequeues is the shallowest one, and you can return immediately. DFS would have to explore every path. The trap: a node with one child is **not** a leaf, so `1 + min(left, right)` with a null side counted as depth 0 is wrong.

## Clamping negative branches (Optional) {theory}

Binary Tree Maximum Path Sum (124) uses the same shape with sums. The function returns the best **downward** path starting at the node (what a parent can extend): `node.val + max(0, left, right)`, where 0 means "do not take that branch". The global answer considers the path that bends at the node: `node.val + max(0, left) + max(0, right)`.

```ex

    why: "Taking 0 means \"stop here\". A path must contain at least one node, which the node itself provides."
  - t: "To avoid returning negative numbers, which recursion cannot handle."
    why: "Recursion handles negatives fine; the clamp is a choice about the path."
    kind: concept
  - t: "Because LeetCode's values are non-negative."
    why: "They can be as low as −1000; that is the whole difficulty."
    kind: concept

```

```ex
type: interview
title: Longest Univalue Path (LeetCode 687)
q: "Return the length (number of edges) of the longest path in which every node has the same value. The path need not pass through the root. Example: `[5,4,5,1,1,null,5]` → 2 (the path 5–5–5 on the right)."
model:
  clarify: |
    - Edges, not nodes.
    - The path can bend at a node (go down both sides).
    - Empty tree → 0.
  brute: "From every node, compute the longest same-value path downwards on each side: O(n²) in the worst case."
  optimize: "Diameter's shape. `arrow(node)` returns the longest downward same-value path starting at node (in edges).     - all values equal → the diameter
    - all values distinct → 0
    - single node → 0
  complexity: "O(n) time, O(h) stack."

  }

  function longestUnivaluePath(root) {

      if (!node) return 0;
```
