<Include id="theory/binary-search-sorting/binary-search-on-the-answer" />

In Koko Eating Bananas there is no array to search. Koko's speed k is unknown; the question is the smallest k that finishes in h hours. But for any *given* k you can easily check whether it works: pile p takes `⌈p / k⌉` hours, so add them up. And faster never hurts: if speed k works, every speed above k works. So the candidate speeds read `F F … F T T … T`, and the answer is the first T.
