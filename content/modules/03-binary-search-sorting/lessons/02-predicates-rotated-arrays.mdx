<Unit id="any-monotone-predicate" kind="theory" title="Any monotone predicate">

First Bad Version (278) has no array at all: versions 1..n, and an API `isBadVersion(v)` that is false up to some version and true from then on. That is a monotone predicate over `[1, n]`, so the first bad version is `firstTrue(1, n + 1, isBadVersion)`. Recognising the predicate is the whole problem.

<Include id="theory/binary-search-sorting/rotated-sorted-arrays" />

Draw `[4, 5, 6, 7, 0, 1, 2]` as heights: a rising run, a drop, a second rising run whose every value is below the first run's. Wherever `mid` lands, at least one of `[lo, mid]` and `[mid, hi]` contains no drop, so it is sorted.

<Unit id="searching-a-target-in-a-rotated-array-stretch" kind="theory" title="Searching a target in a rotated array (Stretch)">

Problem 33 adds a target. Find the sorted half around `mid` (if `nums[lo] <= nums[mid]`, the left half is sorted). A sorted half has a known range, so two comparisons tell you whether the target can be inside it. If it can, search that half; otherwise search the other.
