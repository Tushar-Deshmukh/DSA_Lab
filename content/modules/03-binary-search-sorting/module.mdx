<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

Binary search is the first algorithm where a tiny change (`<` vs `<=`, `mid` vs `mid − 1`) separates a correct solution from an infinite loop. This module replaces memorised templates with one idea, **find the first index where a monotone predicate becomes true**, and applies it to sorted arrays, rotated arrays, matrices, peaks and, in lesson 3, to answers that are not stored anywhere. Lesson 5 covers the sorting algorithms you must be able to explain and the comparators JavaScript requires.

| Lesson | Topic | The idea |
| --- | --- | --- |
| 1 | Lower and upper bound | Search for a boundary `F F F T T T`, not for "the target" |
| 2 | Predicates and rotated arrays | One half around `mid` is always sorted |
| 3 | Binary search on the answer | Feasibility is monotone in the answer |
| 4 | Flattened matrices and peaks | Binary search needs a rule, not sorted data |
| 5 | Sorting | Merge sort, quicksort, stability, comparators |
