<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

Trees are recursion with a shape you can draw. Every tree problem this module starts with one decision: **does the answer come from the children, from the ancestors, or from the levels?** That decision chooses postorder with return values, preorder with parameters, or BFS, before you write a line.

| Lesson | Topic | Question type |
| --- | --- | --- |
| 1 | Terms, traversals, iterative inorder | all three, introduced |
| 2 | Level-order BFS | levels |
| 3 | Height, diameter, balance | from children (bottom-up) |
| 4 | Path sums, good nodes, LCA | from ancestors (top-down), and LCA's three-case contract |
| 5 | Binary search trees, construction | ordering |

The checkpoint is **Assessment 3**.
