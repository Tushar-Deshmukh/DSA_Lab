<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

A graph is any set of things with connections between them: cells in a grid, courses with prerequisites, people who know each other. Every problem this module is a traversal (DFS or BFS) plus one extra idea: count the components, measure distance in layers, respect edge direction, or colour as you go.

| Lesson | Topic | The extra idea |
| --- | --- | --- |
| 1 | Representations, grids, DFS/BFS | mark visited when you push |
| 2 | Components, matrix input, cloning | loop over every node, not just node 0 |
| 3 | BFS shortest paths, multi-source | all sources at distance 0 at once |
| 4 | Directed graphs, topological sort | three states; in-degree 0 goes next |
| 5 | Bipartite, reverse search | two colours; search from the targets |
| Checkpoint | **Assessment 4** | Module 8 milestone check |
