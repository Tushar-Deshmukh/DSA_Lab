  - Write iterative DFS and BFS that mark nodes visited when they are pushed
  - Count islands by sinking each island as it is found

summary:
  - 'Adjacency list: O(V + E) space; the default. Matrix: O(V²), for dense or matrix-given graphs.'
  - 'Undirected: push both directions.'
  - DFS (stack or recursion) and BFS (queue) both run in O(V + E).
  - Mark visited when pushing; marking on pop can enqueue a node many times.
  - 'Grids: check bounds before indexing; recursion on 10⁵ cells can overflow, so use a stack.'
