<Unit id="cloning-a-graph-stretch" kind="theory" title="Cloning a graph (Stretch)">

Clone Graph (133) gives you one node of a connected undirected graph and asks for a deep copy. A `Map` from each original node to its copy does two jobs: it is the visited set (a node is visited iff it has a copy), and it is how you wire a copy's neighbours to the *copies* of the original's neighbours. Create a node's copy the first time you see it; then traverse and push each copy's neighbour list.
