<Unit id="8-directions-and-blocked-ends" kind="theory" title="8 directions and blocked ends">

Shortest Path in Binary Matrix (1091) adds two details: moves go in 8 directions, and the path length counts **cells** (so the start alone is length 1). If the start or the end cell is blocked, the answer is −1 before any search.

<Callout kind="tip" title="Optional: Word Ladder (127)">

An implicit graph: words are nodes and two words are adjacent if they differ by one letter. Comparing every pair of words is O(N² · L). Instead bucket words by patterns with one wildcard (`h*t` → hot, hit); words in the same bucket are neighbours. Then it is plain BFS.
