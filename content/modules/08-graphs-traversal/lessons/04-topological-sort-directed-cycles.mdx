<Callout kind="tip" title="Optional: Find Eventual Safe States (802)">

A node is safe if every path from it ends at a terminal node. With three-state DFS that is exactly "the node finishes in state 2": any node that can reach a cycle gets stuck in state 1 or leads to one.
