<Unit id="constrained-generation-parentheses" kind="theory" title="Constrained generation: parentheses">

Generate Parentheses (22) could be solved by generating every string of `(` and `)` and filtering the valid ones: 2²ⁿ strings. The better state is two counts. A `(` is allowed while fewer than n have been used; a `)` is allowed only while it would close an unmatched `(`. With those two rules every complete string is valid, so nothing is filtered afterwards.

<Unit id="string-backtracking-palindrome-partitioning-stretch" kind="theory" title="String backtracking: Palindrome Partitioning (Stretch)">

Problem 131 asks for every way to cut a string into palindromic pieces. The decision at each level is **where the next piece ends**: from `start`, try every `end` such that `s[start..end]` is a palindrome, push that piece, recurse from `end + 1`, pop. Record when `start` reaches the end of the string.
