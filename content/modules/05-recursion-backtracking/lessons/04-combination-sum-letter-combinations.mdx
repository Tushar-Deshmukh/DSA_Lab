<Unit id="reuse-allowed" kind="theory" title="Reuse allowed">

Combination Sum (39) lets you use a candidate any number of times. The state is (start index, remaining target). Recursing with the **same** `i` lets the next level pick the same candidate again; never going *below* `i` stops `[3, 2, 2]` from appearing after `[2, 2, 3]`.
