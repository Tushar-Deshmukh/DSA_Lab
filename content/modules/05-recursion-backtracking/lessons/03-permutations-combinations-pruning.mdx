<Callout kind="tip" title="Optional: Permutations II (47)">

With duplicates, sort and add `if (i > 0 && nums[i] === nums[i - 1] && !used[i - 1]) continue;`. It forces equal values to be placed in left-to-right order, so each distinct arrangement is produced once.
