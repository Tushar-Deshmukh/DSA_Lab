<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

Arrays give you positions; linked lists give you pointers; stacks and queues give you an order of access. This module is about **discipline with references**: never lose the rest of a list, always know what the top of a stack means, and never pay O(n) for an operation that should be O(1).

| Lesson | Topic | The move you learn |
| --- | --- | --- |
| 1 | Linked lists, dummy nodes, reversal | Save `next` before you rewire |
| 2 | Fast and slow pointers | Two speeds find middles, cycles and k-th from the end |
| 3 | LRU cache | Map for lookup + doubly linked list for order |
| 4 | Stacks, queues, deques | LIFO for nesting; a head pointer instead of `shift()` |
| 5 | Monotonic stack and deque | Pop what can never be an answer again |

The checkpoint is **Assessment 2** and the Module 4 milestone check.
