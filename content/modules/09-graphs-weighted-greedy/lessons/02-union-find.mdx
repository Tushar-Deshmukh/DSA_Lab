  - Each set is a tree; `find` walks to the root; the root names the set.

  - 'Union by size: the smaller tree goes under the larger root.'

  - '`union` returns false when already connected: that edge would close a cycle.'
  - DSU cannot split sets, so it cannot handle edge deletions.
