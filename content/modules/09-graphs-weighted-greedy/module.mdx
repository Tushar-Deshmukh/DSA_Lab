<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

In the previous module every edge cost the same, so BFS layers were distances. This module edges have weights, sets of nodes merge as edges arrive, and some problems can be solved by a single sequence of locally best choices. The common thread is **proving** that a simple rule is safe: "the popped node is final" (Dijkstra), "the cheapest edge between two trees is safe" (MST), "the earliest-ending interval can always be kept" (greedy).

| Lesson | Topic | The rule you must be able to justify |
| --- | --- | --- |
| 1 | Dijkstra | with non-negative weights, the closest unfinished node is final |
| 2 | Union-Find | roots identify sets; small trees go under large ones |
| 3 | Minimum spanning tree | the cheapest edge joining two trees is always safe |
| 4 | Greedy and counterexamples | swap the greedy choice into any optimal solution |
| 5 | Greedy with a running quantity | one variable summarises everything a DP would store |
| Checkpoint | **Module review + Mock 3** | interview conditions, scored |

<Callout kind="warn" title="Greedy is the topic most often got wrong">

Greedy solutions are short and they often pass the sample tests even when they are wrong. This module you practise the habit that protects you: before coding a greedy idea, spend three minutes trying to break it with a 2–4 element input.

</Callout>
