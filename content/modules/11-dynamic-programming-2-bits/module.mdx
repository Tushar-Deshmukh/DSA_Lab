<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

Module 10's DP used one index. This module the state grows: an item index plus a capacity (knapsack), two prefix lengths (two strings), an "ending at i" element (LIS), or a mode (holding a stock or not). Lesson 5 changes topic to bit manipulation, which is short, mechanical and full of JavaScript-specific traps.

| Lesson | Topic | State or tool |
| --- | --- | --- |
| 1 | 0/1 knapsack (416, 494) | `dp[j]`, iterated **downwards** |
| 2 | Two sequences (1143, 72) | `dp[i][j]` for two prefixes |
| 3 | LIS (300) and palindromes (5, 647) | "ending at i"; 2n − 1 centres |
| 4 | State machines (309) and recognition | one variable per mode |
| 5 | Bits (136, 191, 338, 268) | XOR, `x & (x − 1)`, 32-bit rules |
