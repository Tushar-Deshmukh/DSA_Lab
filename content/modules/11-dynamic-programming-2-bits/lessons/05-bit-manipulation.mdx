summary:
  - Bitwise operators work on signed 32-bit integers; results are signed.
  - Check `(x >> i) & 1`; set `|`; clear `& ~`; toggle `^`; drop lowest `x & (x − 1)`; isolate `x & −x`.
  - 'XOR: x ^ x = 0, x ^ 0 = x, order-independent.'
  - '338: `bits[i] = bits[i >> 1] + (i & 1)`.'
  - '`>>>` is the logical shift; `x >>> 0` reads the 32 bits as unsigned.'
  - Never use bit operators on values beyond 32 bits.
