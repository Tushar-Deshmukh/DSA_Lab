summary:
  - '`dp[i][j]` = answer for `a[0..i)` and `b[0..j)`; table (m + 1) × (n + 1).'
  - 'LCS: match → diagonal + 1; else max(top, left). Base 0.'
  - 'Edit: match → diagonal; else 1 + min(top = delete, left = insert, diagonal = replace). Base i and j.'
  - O(m·n) time; two rows → O(min(m, n)) space.
