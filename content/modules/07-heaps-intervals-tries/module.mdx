<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

Three structures, each answering one question fast. A **heap** answers "what is the smallest (or largest) right now?" while elements keep arriving. **Sorted intervals** answer "what overlaps what?" with a single pass. A **trie** answers "which words start with this?" in time proportional to the prefix, not the dictionary.

| Lesson | Topic | The question it answers |
| --- | --- | --- |
| 1 | Binary heap from scratch | the minimum, under pushes and pops |
| 2 | Top-K and k-way merge | the k best, or the next in global order |
| 3 | Two heaps, task scheduling | the median, or the next task to run |
| 4 | Intervals and sweeps | overlaps, merges, rooms in use |
| 5 | Tries | prefixes and wildcards |

JavaScript has no built-in priority queue, so lesson 1's 35-line `MinHeap` is a tool you will use for the rest of the course (Dijkstra, Prim, scheduling).
