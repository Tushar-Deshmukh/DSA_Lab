summary:
  - Heap = complete binary tree with parent ≤ children (min-heap), stored in an array.
  - 'push: append, sift up while smaller than the parent. pop: move the last to the root, sift down to the smaller child.'
  - peek O(1); push/pop O(log n); heapify O(n); arbitrary search O(n).
  - 'Max-heap: comparator `(a, b) => b − a`. Tuples: `(a, b) => a[0] − b[0]`.'

<Unit id="heapify-in-o-n" kind="theory" title="Heapify in O(n)">

To build a heap from n unordered elements, n pushes cost O(n log n). Sifting down every non-leaf, from the last one to the root, costs O(n): most nodes are near the bottom and can only move a level or two.
