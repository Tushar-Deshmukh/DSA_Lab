<Unit id="task-scheduler" kind="theory" title="Task Scheduler">

Problem 621: tasks with a cooldown of n between two copies of the same task; find the minimum time, idling when needed. Simulate it first, then look at the picture: the most frequent task forms `maxFreq` rows of width `n + 1`, the last row only as wide as the number of tasks tied for that frequency. Other tasks fill the gaps; if there are more tasks than gaps, there is no idle at all.
