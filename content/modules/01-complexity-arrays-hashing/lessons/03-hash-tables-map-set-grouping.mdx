<Unit id="stretch-longest-consecutive-sequence" kind="stretch" title="Stretch: Longest Consecutive Sequence">

Problem 128 asks for O(n). Sorting would be O(n log n). The trick is to put everything in a Set and **only start counting at the beginning of a run**: a value x where x − 1 is absent. Every value is then visited a constant number of times.

<Callout kind="mistake" title="Mistakes to watch for in this lesson">

- Using a plain object as a counter with numeric keys, then being surprised that keys come back as strings.
- `map[key] = value` on a `Map`: it sets an object property, not a Map entry. Use `set` and `get`.
- Using arrays as Map keys.
- Joining counts without a separator in a count signature.
- Saying "O(1)" for a hash lookup without "average".
