<Unit id="how-this-module-fits-together" kind="overview" title="How this module fits together">

Everything in the next eleven modules is judged by one question: *how does the work grow as the input grows?* This module gives you the tools to answer it (lesson 1), the cost model of JavaScript's arrays (lesson 2), the data structure that makes most brute force fast (hash maps, lessons 3–4) and the index arithmetic of grids (lesson 5).

| Lesson | Topic | The move you learn |
| --- | --- | --- |
| 1 | Complexity | Count operations as n grows; read n from the constraints |
| 2 | Arrays and in-place edits | Keep an invariant while overwriting the same array |
| 3 | Hash tables | Replace an inner search loop with an O(1) average lookup |
| 4 | Frequency counting | Count, then bucket by count instead of sorting |
| 5 | Matrices | Walk boundaries; rotate by transpose + reverse |
