```ex
type: interview
title: Count Ways To Build Good Strings (LeetCode 2466)
q: "Start with an empty string. Each step appends either `'0'` exactly `zero` times or `'1'` exactly `one` times. Count the distinct strings whose length is between `low` and `high` inclusive, modulo 10⁹ + 7. Example: low = 3, high = 3, zero = 1, one = 1 → 8."
model:
  clarify: |
    - Different sequences of appends always give different strings, so count sequences.
    - Lengths up to 10⁵: the answer needs the modulo.
  brute: "Recursion `f(len)` = 1 (if len is in range) + f(len + zero) + f(len + one): exponential."
  optimize: |
    This is Climbing Stairs with steps of size `zero` and `one`. State: `dp[L]` = number of strings of length exactly L. Transition: `dp[L] = dp[L − zero] + dp[L − one]` (when those indices are ≥ 0). Base: `dp[0] = 1`. Answer: the sum of dp[low..high]. Take the modulo after every addition.
  edges: |
    - zero === one: both choices still count separately ('0'… vs '1'…)
    - low = high
    - high large, so the modulo matters
  complexity: "O(high) time and space."
fn: countGoodStrings
starter: |
  function countGoodStrings(low, high, zero, one) {

  }
solution: |
  function countGoodStrings(low, high, zero, one) {
    const MOD = 1000000007, dp = new Array(high + 1).fill(0);
    dp[0] = 1; let total = 0;
    for (let L = 1; L <= high; L++) {
      if (L >= zero) dp[L] = (dp[L] + dp[L - zero]) % MOD;
      if (L >= one) dp[L] = (dp[L] + dp[L - one]) % MOD;
      if (L >= low) total = (total + dp[L]) % MOD;
    }
    return total;
  }
```

```ex
    The skip distance depends on i, so a forward state is awkward but a **suffix** state is natural. `dp[i]` = the best total from questions i..n−1. Transition: `dp[i] = max(dp[i + 1], points[i] + dp[i + brainpower[i] + 1])`, treating indices ≥ n as 0. Fill from right to left; the answer is dp[0].

    - a skip that jumps past the end

  function mostPoints(questions) {

  }

  function mostPoints(questions) {
    const n = questions.length, dp = new Array(n + 1).fill(0);

      const [p, b] = questions[i];
      dp[i] = Math.max(dp[i + 1], p + (i + b + 1 <= n ? dp[i + b + 1] : 0));
    }
    return dp[0];
  }
```

Assessment 5 is 90 minutes: one cold re-solve chosen at random from the listed set, plus unseen problems. Open the Assessments page for the rules, the timer and the rubric, and do not look at the problems' pages beforehand. For DP problems, write the state sentence as a comment before any code: it earns partial credit even if the code is unfinished.

:::tip If a DP problem stalls
Fall back to the four steps out loud: brute-force recursion first, then memoise it. A correct memoised solution usually scores well even if you never reach the table.
:::
